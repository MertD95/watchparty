Want to test real rooms and syncing?

The playground above uses sample data. For real room testing, use the local backend and the unpacked extension in a separate Chrome profile.

  1. Open chrome://extensions, enable Developer mode, then choose Load unpacked.
  2. Select C:\Users\mertd\WatchParty\watchparty\extension. If already loaded from that folder, click Reload instead. Avoid enabling the store and unpacked copies together.
  3. In WatchParty's extension options, open Connection and select Local development.
  4. Open Stremio Web and use the WatchParty sidebar. If prompted, allow local-network access so it can connect to your local server.

The local backend should be available at localhost:8181/health. Use separate browser profiles with the unpacked extension for separate users; two tabs in one profile are the same user.
